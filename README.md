# 4-20-to-Modbus

Прошивка преобразователя сигнала 4–20 мА в Modbus RTU на STM32F103C8T6.

Используются FreeRTOS, ADC1, TIM3 для запуска измерений, DMA1 и USART1.
В коде предусмотрены функции Modbus `0x03`, `0x06` и `0x10`.

## Проект

- `App/Src`, `App/Inc` — логика измерений, Modbus, UART, настройки и индикация.
- `Core` — запуск, GPIO, тактирование и обработчики прерываний.
- `App/RTOS` — FreeRTOS; `Drivers` — CMSIS и STM32 HAL/LL.
- `4-20-to-Modbus.ioc` — конфигурация STM32CubeMX.
- `4-20-to-Modbus.code-workspace`, `.eide/eide.yml` — проект VS Code/EIDE.
- `.project`, `.cproject` — проект STM32CubeIDE.

## Состояние

Проект находится на стадии прототипа. Сборка Debug проверена с Arm GNU GCC
14.3.1; проверка на устройстве не выполнялась. Обнаружены ошибки обработки
кадров, применения настроек связи и организации измерений.

Подробности и порядок исправления: [CODE_REVIEW.md](CODE_REVIEW.md).

По текущей реализации настройки по умолчанию: адрес `1`, `9600`, `8N1`.
Их сохранение через регистр `0x0000` пока не реализовано во Flash.

## Регистры

| Адрес | Назначение | Доступ |
| --- | --- | --- |
| `0x0000` | Применение настроек связи | RW |
| `0x0001` | Адрес устройства | RW |
| `0x0002` | Код скорости: 0…7 → 1200…115200 бод | RW |
| `0x0003` | Чётность: 0 — нет, 1 — even, 2 — odd | RW |
| `0x0004` | Стоповые биты | RW |
| `0x0100` | Ток, мкА | RO |
| `0x0101` | Напряжение АЦП, мВ | RO |
| `0x0102` | Отсчёт АЦП | RO |
| `0x0103` | Статус, сейчас всегда 0 | RO |

Таблица описывает назначение регистров в исходниках. Ограничения и ошибки
их обработки перечислены в отчёте.
